
# StudentPortal - Student Management System

## Project Overview
StudentPortal is a web-based Student Management System developed using Spring MVC. It allows users to manage student records efficiently.

## Technologies Used
- Java
- Spring MVC
- Spring JDBC
- JSP
- JSTL
- MySQL
- Maven
- Apache Tomcat

## Features
- Add Student
- View All Students
- Edit Student Details
- Delete Student
- MySQL Database Integration

## Architecture
The application follows Model-View-Controller (MVC) architecture.

- Model: Student.java
- View: JSP pages
- Controller: StudentContrller.java
- DAO: StudentDAO.java
- Database: MySQL

## Database
Database Table: students71

Fields:
- id
- fname
- lname
- email
- age
- city
- state

## How to Run
1. Clone the repository.
2. Import the project into Eclipse as an existing Maven project.
3. Configure MySQL database.
4. Update database connection settings.
5. Run the application using Apache Tomcat.
6. Open the application in your browser.
